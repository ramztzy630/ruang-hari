# Perbaikan tata letak pencarian dan tombol tutup

Hanya `dist/style.css` yang berubah (CSS ditambahkan di akhir file); tidak ada perubahan JS/Kotlin.

- Hasil "Cari lagu online": baris lagu kini rata kiri (sampul di pojok kiri, judul dan artis di sebelahnya, teks rata kiri).
- Pemutar (kartu dan layar penuh): tombol tutup × kini 44x44 px dengan latar bulat dan ikon 28 px, dan "Sound of the day" ikut diperbesar area sentuhnya.
- Judul lagu di pemutar kini rata kiri (sebelumnya terdorong ke kanan).

Belum diverifikasi visual di perangkat. Build ulang lewat GitHub Actions seperti biasa.
